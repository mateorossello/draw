# Draw

Practice project - Random winner picker

---

## Features

-   Perform a draw from a list of names.
-   Prevents errors by validating user inputs.

---

## How to get started

No installation is required. Simply clone the repository and open **index.html** in any modern web browser.
Alternatively, you can access the live version deployed on **GitHub Pages**.

---

-   **Language:** JavaScript
-   **Styling:** CSS
-   **Markup:** HTML
